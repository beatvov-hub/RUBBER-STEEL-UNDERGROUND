■ 動作環境
Windows 10 / 11（64bit）、キーボード・マウス。1280×800以上推奨。
ネットワーク、アカウント、Node.jsのインストールは不要です。

■ ゲーム概要
見下ろし型ローグライト・アクションシューティング。50ステージ×各10フロア、計500フロア。
自分が撃った弾は、敵に命中するまで消えません。壁で何度でも跳ね返り、自分にも当たります。
左下のENTRYから入り、敵を全滅させて右上のEXITへ進んでください。
敵全滅後も自弾は残り、次フロアへの移動時だけ一掃されます。
各ステージの10階はエリート戦。ステージ10・20・30・40・50にはエリアボスがいます。
ステージをクリアすると次のステージが解禁されます。

■ 戦闘と成長
STANDARD / TRIPLE SHOT / HEAVY SHOTをいつでも切り替えられます。
2・4・6・8階の脱出後、3候補から一時能力を1つ選択します。死亡すると一時能力を失います。
装甲敵は最初の命中で装甲が壊れ、撃った弾が反射します。重弾でもこの反射は起こります。
最大アクティブ弾数は敵弾を含め180。上限時は新しい射撃だけ停止し、古い自弾は残ります。
STANDARDは初期解禁。FIRE / ICE / THUNDERはステージ10 / 20 / 30クリアで解禁されます。
後半では可動壁と崩落床が登場します。予告表示を確認してください。

■ インストール・起動
配布ZIPをすべて展開し、RUBBER_STEEL_UNDERGROUND.exeを起動してください。
ZIP内のファイルを個別に移動せず、フォルダ構成を保ってください。
ブラウザー版を開発環境で起動する場合は、Node.js 22以降で npm ci → npm run dev。

■ アンインストール
配布フォルダを削除してください。設定と進行記録も消す場合は、
%APPDATA%\rubber-steel-underground のデータを削除してください。
ブラウザー版ではサイトデータを削除すると設定と進行記録が消えます。

■ 操作
WASD / 矢印キー: 移動
マウス: 照準
左クリック（長押し可）: 射撃
1 / 2 / 3: 武器切替
Esc / PAUSE: 一時停止・再開
R: 死亡時のフロア再挑戦
ゲーム画面からフォーカスが外れると自動的に一時停止します。
自弾は白・青のトレーサー、敵弾はオレンジ色のひし形です。

■ 保存と設定
ステージ解禁、キャラクター解禁、クリア記録、総プレイ時間、設定をローカルに保存します。
RUN途中の一時能力・フロア内の状態は保存されません。
SETTINGSからMASTER / BGM / SFX、画面揺れ、発光、キーガイド、全画面表示を調整できます。

■ クレジット・素材
ゲーム内図形、UI、効果音、BGMはプログラム生成。外部画像・音声素材は使用していません。
開発技術: TypeScript、Vite、Electron。各ライセンスは配布物内の該当LICENSEを参照してください。
