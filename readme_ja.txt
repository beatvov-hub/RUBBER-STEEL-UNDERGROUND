■ 動作環境
Windows 10 / 11 64bit、キーボード・マウス。
ブラウザ版: 最新のChrome / EdgeなどCanvas・Web Audio対応ブラウザ。
解像度: 1280×800以上推奨。ネットワーク、アカウント不要。

■ ゲーム概要
見下ろし型ローグライト・アクションシューティング。
自分の弾は敵に当たるまで消えず、壁で何度でも反射します。
自弾、敵弾、敵との接触で死亡します（初期HP 1）。
左下のENTRYから始め、敵全滅後に右上のEXITへ進んでください。
敵が全滅しても自弾は残ります。フロア移動時にのみ一掃されます。
STAGE 1は10フロア。10Fにボスがいます。
2 / 4 / 6 / 8Fを脱出すると、3候補から能力を1つ選べます。
アーマー敵は初弾を反射し、次の命中で倒せます。重弾も初弾は反射。
STANDARD / TRIPLE SHOT / HEAVY SHOTを自由に選択できます。
最大180発（敵弾を含む）では新規射撃が止まります。古い自弾は消しません。
死亡時、取得能力を失います。RETRY FLOORは現在のフロアから標準装備で再開します。

■ 起動方法
Windows配布版: ZIPをすべて展開し、RUBBER_STEEL_UNDERGROUND.exeを起動。
利用者のNode.jsインストールは不要です。
開発版: Node.js 22以上を用意し、npm ci → npm run dev。
表示されたローカルURLをブラウザで開いてください。
本番ビルド: npm run build / Windows配布ZIP生成: npm run package:win

■ アンインストール方法
配布フォルダを削除してください。
Windows設定保存先: %APPDATA%\rubber-steel-underground
完全削除する場合はこのフォルダも削除してください。
ブラウザ版はサイトデータを削除すると設定・記録が消えます。

■ 操作方法
WASD / 矢印キー: 移動
マウス: 照準
左クリック（長押し可）: 射撃
1 / 2 / 3、画面下の武器ボタン: 武器切替
Esc / PAUSE: 一時停止・再開
R: 死亡時のフロア再挑戦
SOUND ON/OFF: 音の切替
フォーカスが外れると自動的に一時停止します。
黄緑: 自弾 / サーモン色: 敵・敵弾 / 水色: 敵アーマー。

■ 保存
ローカルに音設定、到達フロア、クリア最速時間を保存します。
解禁キャラクター・到達STAGE用の保存項目は将来拡張用です。
RUN途中の保存・ロードはありません。
